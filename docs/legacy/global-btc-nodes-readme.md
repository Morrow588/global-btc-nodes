# Global BTC Nodes Dashboard 🌐

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://global-btc-nodes.preview.emergentagent.com/)
[![Built by Virtual Traders](https://img.shields.io/badge/Built%20by-Virtual%20Traders-blue)](https://virtualtraders.com)

A comprehensive dashboard for monitoring Bitcoin nodes across the globe. Real-time tracking and analytics for Bitcoin network nodes.

## ✨ Features

- **🌍 Global Node Map** - Visual representation of Bitcoin nodes worldwide
- **📊 Real-time Statistics** - Live node count and network health metrics
- **⚡ Performance Monitoring** - Node uptime and response times
- **🔔 Alert System** - Notifications for node status changes
- **📈 Analytics Dashboard** - Historical data and trends analysis

## 🚀 Quick Start

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- MongoDB (for data storage)

### Installation

```bash
# Clone the repository
git clone https://github.com/virtualtraders/global-btc-nodes.git

# Navigate to project directory
cd global-btc-nodes

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your configuration

# Start the development server
npm run dev
